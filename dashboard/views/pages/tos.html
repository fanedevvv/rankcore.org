IP Verification System
Terms governing the optional IP-based security feature — Added March 2026
What is IP Verification? IP Verification is an optional security feature that server administrators may enable. When enabled, members who click the verification button are directed to a one-time secure link where they consent to having their IP address collected, analysed, and stored. Consent is mandatory and enforced both client-side and server-side — verification cannot be completed without it.

Informed Consent is Required

Before any IP data is collected, users must explicitly agree to the data collection notice presented on the verification gate page. This consent is validated server-side — no data is collected without it. By clicking "Complete Verification" you agree to the IP data practices described in our Privacy Policy.

Token Security

Each verification link is a one-time-use token generated from 48 cryptographically random bytes. Tokens are stored only as SHA-256 hashes — plaintext is never persisted. Tokens expire at a TTL configured by the server administrator (5–30 minutes) and are bound to a specific user/guild pair.

Data Collected During Verification

When you complete IP Verification, the following data is collected and stored in encrypted form:

IP Address Threat Intelligence Discord User ID Guild ID Verification Result Timestamp

Automated Actions by Server Administrators

Server administrators configure the system's response to failed checks. Depending on settings, a failed or flagged verification may result in an automated kick, ban, or alert within the Discord server. These actions are taken by the server administrator's configuration — not unilaterally by RankCore.

Re-Verification

Server administrators may configure a re-verification interval (default 30 days). You may be required to complete IP Verification again after this interval. Each re-verification generates a new one-time token and requires fresh consent.

Your Right to Deletion

Server administrators may delete individual verification records via the dashboard. Users may request deletion of their verification record by contacting the server administrator or our support team. See the Privacy Policy for full details on data retention and GDPR rights.

Evasion Prohibited Attempting to circumvent the IP Verification system — including using VPNs, proxies, Tor, or alt accounts — after being blocked by a server's policy constitutes a violation of Section 03 (Forbidden Conduct) and may result in global blacklisting. You consented to these checks when you initiated verification.

Ticket System — Data & Conduct
Terms governing the support ticket feature — Added May 2026
Message Recording Notice By sending messages in any ticket channel created by RankCore, you acknowledge and consent that the full conversation — including text content, file attachments, and images — may be saved as a transcript accessible to that server's administrators and to RankCore staff for operational and security purposes. Do not share passwords, financial information, or other sensitive credentials in ticket channels.

Transcript Storage & Consent

When a ticket is closed, a full HTML and/or web transcript of the conversation is generated and stored. By participating in a ticket, you consent to this storage. Transcripts are retained in accordance with Section 05 of the Privacy Policy (Data Retention). Ticket owners may request deletion of their transcript data via support@rankcore.org.

Administrator Access & Actions

Server administrators and configured ticket handler roles may view all ticket transcripts, add staff notes, set priorities, assign tickets, apply tags, and perform moderation actions (close, lock, delete). These actions are logged. Administrators are prohibited from using ticket data for purposes unrelated to server moderation or support operations.

Prohibited Use of Tickets

The following conduct within ticket channels is strictly prohibited and may result in immediate blacklisting:

Opening false/spam tickets Abuse of ticket staff Sharing NSFW/illegal content Attempting to extract sensitive server info Coordinated mass ticket flooding

Ratings & Intake Responses

Satisfaction ratings (1–5 stars) submitted after ticket closure are stored in association with your Discord User ID and the relevant ticket record. Intake question responses provided when opening a ticket are stored in the ticket record and visible to server administrators. This data is included in the scope of any GDPR or CCPA erasure request.

Auto-Close & Inactivity

Server administrators may configure automatic ticket closure after a defined period of inactivity. Users will receive a warning before auto-closure. Tickets closed automatically generate a full transcript in the same manner as staff-closed tickets. This is disclosed here as a processing activity under GDPR Article 13.

Staff Notes Confidentiality Staff notes added within ticket channels are internal records visible only to users with the ticket handler role and server administrators. They are not shown to ticket owners by default. However, they are included in any data access request made under GDPR or CCPA.
