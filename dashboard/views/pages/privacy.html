04
Infrastructure & Security
How your data is protected
AES-256 Encryption at Rest

All sensitive data including IP addresses, User IDs, and verification records are encrypted at rest using AES-256.

HMAC-Based Lookups

User IDs and IP addresses used for deduplication are stored as HMAC hashes — one-way transforms that cannot be reversed.

Least-Privilege Access

Strict internal access controls. Only the minimum required team members have access to production data, and all access is audited.

Isolated VPC Environments

Database and compute infrastructure is isolated in private VPCs not exposed to the public internet.

05
Data Retention & Erasure
Your right to be forgotten

Server Removal (30 Days)

If a server removes the bot, all configurations and associated logs are queued for deletion, processed every 30 days to prevent data loss from accidental bot kicks.

On-Request Erasure

Exercise your right to erasure by contacting support@rocobot.xyz or using the /privacy delete command in Discord. Production data is removed immediately.

IP Verification Record Retention

IP Verification records are retained for as long as the server's configuration is active, or until manually deleted by the server administrator or upon a user erasure request. Records deleted by an administrator are immediately removed from production.

Backup Persistence (90 Days)

While data is removed from production immediately following an erasure request, it may persist in encrypted off-site backups for up to 90 days before being completely overwritten.

What Administrators Can See

Server administrators can view verification records via the Roco dashboard. The IP address displayed to administrators is always masked as [hidden] — they cannot see your actual IP. They can see: verification outcome, flag reasons, country, risk score, ISP, VPN/proxy flags, and your Discord User ID. They can delete any record, manually approve a blocked user, or manually ban them.

Anti-Bypass Technical Guarantees

  • The verification token is 48 cryptographically random bytes, stored as SHA-256 hash only — never in plaintext.
  • Each token is strictly one-use. It is burned (marked used) the moment your POST request is received.
  • Tokens have a server-configured TTL of 5–30 minutes. Expired tokens are deleted from the database.
  • The token is bound to your specific Discord User ID and Guild ID — it cannot be used by a different person.
  • Rate limiting: a maximum of 3 active tokens per user per guild per TTL window.
  • Your IP address is captured entirely server-side — it cannot be faked or spoofed by the client.

Your Consent Rights

IP Verification always requires your explicit consent via a checkbox on the verification gate page. Consent is validated server-side — the system will not process your IP without it. You may withdraw participation by not completing the verification flow, though this may restrict your access to the server per the administrator's configuration.

Erasure of Verification Records

You may request deletion of your IP Verification record at any time by contacting the server administrator, who has a per-record delete function in the dashboard, or by contacting Roco support at support@rocobot.xyz with your Discord User ID and the server name. Records deleted from production are removed immediately; backup copies are purged within 90 days.

Who Can Access Ticket Data

Server administrators and users with the configured ticket handler role can view all open and closed ticket records via the Roco dashboard, including transcripts. Roco developers may access ticket records only for the purposes of security investigations, bug fixes, or when responding to a legal request. Ticket data is never shared with third parties beyond what is described in Section 03 (infrastructure providers).

Transcript Retention

HTML transcript files and web transcript records are retained as long as the server's bot configuration is active. When a server removes the bot, all ticket records — including transcripts — are queued for deletion within 30 days. Individual ticket records can be deleted at any time by a server administrator via the dashboard. Users may request deletion of their participation data (including message content from transcripts) by contacting support@rocobot.xyz with their Discord User ID and server name.

Important Notice: Message Content

By using a server's ticket system, you acknowledge that all messages sent within a ticket channel may be captured and stored as a transcript. This includes text, images, and file attachments. Transcripts are accessible to server administrators. Do not send sensitive personal information (such as passwords, financial data, or government ID numbers) in ticket channels.
