How it works

User clicks Verify in Discord → bot generates a one-time URL with configurable expiry.

IP is checked against VPN / proxy / country databases. Country allowlist/blocklist lets you geo-restrict your server.

Alt detection cross-references IPs. IP ban threshold auto-blocks IPs with repeated violations.

Separate fail and flagged actions. Webhooks fire on pass/fail to any HTTP endpoint.
