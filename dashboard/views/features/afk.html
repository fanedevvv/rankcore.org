How it works

Set AFK Status
Users can use /afk set [reason] to go AFK
Nickname Change
Bot automatically changes nickname to [AFK] Username
Auto Remove
AFK is automatically removed when user sends a message
Mention Notification
When mentioning an AFK user, a notice shows their reason and duration
Global AFK
Users can use --global flag to set AFK in all servers
