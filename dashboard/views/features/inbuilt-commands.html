Staff Commands

Configure /promote and /infract — built-in staff action commands

⚠️ Demo (Demotion)
Temporary demotion — used as a first-step action. Can change roles automatically.
🔔 Warning
Formal logged warning. Builds a staff record that can be referenced later.
⛔ Suspension
Temporary removal from duties. Staff role can be auto-stripped for a set duration.
🚫 Removal
Permanent removal from staff. All roles in the promotion chain are stripped.
Command Syntax
/infract @user [demo|warning|suspension|removal] [reason]
/promote @user [to-rank] [reason]
/stafflog @user — view history
