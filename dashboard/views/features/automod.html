How to Change the Automod Log Channel in Discord

Step 1: Open Server Settings → Moderation → Auto Moderation

Navigate to your Discord server settings, then select the Moderation tab and open Auto Moderation.

Step 2: Click the Rule You Want to Log

Select the automod rule you want to track (Keyword Filter, Spam, or Blocked Links).

Step 3: Select the Log Channel

Scroll down to the Audit Log Channel option and choose the text channel where you want automod actions to appear.

Step 4: Save Changes

Click Save Changes to apply the new log channel.

Tip: Make sure your bot has View Channel and Send Messages permissions in the selected channel.
