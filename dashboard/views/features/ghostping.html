Ghost Ping Detection

When enabled, RankCore will detect any deleted message that contained a @mention and publicly call out the sender.

🔍 What counts as a ghost ping? Any message that @mentioned a user or role but was deleted by the sender.

📢 What happens? RankCore sends a public alert in the same channel revealing the original message content and who sent it.

⚙️ Bots are excluded — bot messages are never flagged.

Changes save immediately when you toggle above.
