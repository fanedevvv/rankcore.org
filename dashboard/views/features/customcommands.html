Help & Reference
⚡ Basic

Command Name — registers as a Discord slash command (e.g. /greet). Lowercase, numbers and hyphens only. No spaces.

Description — shown in Discord's command picker. Max 100 chars.

Response — supports Discord markdown and variables like {user.mention}.

📝 Variables
{user.mention}Pings the invoker
{user.tag}Username like john#1234
{user.id}Discord User ID
{server}Server name
{memberCount}Total members
{channel}Channel name
{random:1-100}Random number
{arg:name}Value of an argument
{arg:name.mention}Mention from USER/ROLE arg
{arg:name.url}URL from FILE arg
🔤 Argument Types
