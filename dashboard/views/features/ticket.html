How Tags Work

Tags let staff categorise open tickets with custom labels like "Awaiting User", "In Progress", or "Escalated".

Staff click the 🏷️ Tag button inside a ticket channel. Multiple tags can be applied at once.

Applied tags are saved and displayed in the transcript log and closed ticket summary.
