Feature Toggles

Enable or disable individual features of the suggestion system.

Review Mode

New suggestions go to the Review Channel first. Mods approve them before they appear publicly.

Create Discussion Thread

Automatically starts a thread under each suggestion for community discussion.

DM Author on Result

Sends the suggestion author a DM when their suggestion is approved, rejected, or implemented.

Allow Suggestion Edits

Authors can edit their suggestion before it receives any votes. Staff can always edit.

Require Reason on Reject

Forces moderators to provide a written reason when rejecting a suggestion.

Anonymous Mode

Hides the author's identity in the suggestion embed. Staff can still see who submitted via /suggestion info.

Allow Self-Vote

Authors can vote on their own suggestions. Disabled by default to prevent gaming.

Allow Vote Change

Users can switch from upvote to downvote (and vice versa) after casting their vote.

Content Limits

Control the length of suggestion content.

Minimum characters required. 0 = no minimum.

Maximum characters allowed. Max 1024.

Submission Limits

Prevent spam and limit per-user activity.

How long a member must wait between suggestions. 0 = no cooldown.

Maximum pending/under-review suggestions a single user can have at once. 0 = unlimited.

Vote Thresholds

Automatically resolve suggestions based on vote counts.

Automatically approve a suggestion when it reaches this many upvotes. 0 = disabled.

Automatically reject a suggestion when it reaches this many downvotes. 0 = disabled.

Auto-Close

Automatically close voting after a set time.

Voting buttons are disabled after this many hours. 0 = voting never closes automatically.

Auto-actions send DMs

When a suggestion is auto-approved/rejected by threshold, the author receives a DM (requires DM on Result to be enabled).
